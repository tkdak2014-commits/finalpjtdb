# 지하주차장 유지보수·안전성 검사 로봇 BR/SR

> 적용 범위: 누수·고임, 조명 이상, 적치물·방치물, 바닥·천장·기둥 손상 후보 탐지  
> 제외 범위: 화재·고온·열원·연기·가스 탐지 및 법정 구조안전진단

## 1. Business Requirement

**사업적으로 어떤 문제를 해결하고 어떤 성과를 낼 것인가?**

| ID | 핵심 요구사항 | 객관적 핵심 성과지표·검증 목표 |
|---|---|---|
| BR-01 | 지하주차장의 순찰 공백과 CCTV 사각지대를 최소화한다. | 4시간마다 1회 점검, 순찰 임무 완료율 95% 이상, 지정 점검지점 방문율 98% 이상 |
| BR-02 | 누수·고임과 통행 방해 요소를 조기에 발견하여 안전사고 위험을 줄인다. | 누수·고임 재현율 85% 이상, 주행로 적치물 재현율 90% 이상, 비상구 적치물 재현율 95% 이상 |
| BR-03 | 조명 이상과 시설물 손상 후보를 발견하여 예방정비를 지원한다. | 조도 기준 미달 판정 정확도 95% 이상, 시설물 손상 후보 정밀도·재현율 각각 80% 이상 |
| BR-04 | 반복 순찰을 자동화하여 시설관리자의 업무 부담을 줄인다. | 순찰시간의 90% 이상 자율운행, 임무당 수동 개입 1회 이하, 월간 순찰 인력시간 40% 이상 절감 |
| BR-05 | 이상 위치와 근거 데이터를 제공하여 빠른 현장 확인과 사후 분석을 지원한다. | 위치오차 1m 이하, 이벤트의 99% 이상에 시간·위치·이미지·측정값·위험등급 포함 |

| SR-05 | 장애·통신단절·배터리 부족·침수 위험 상황에서 안전하게 정지·우회하거나 충전 도크로 복귀한다. | 위험구역 진입 및 충돌 0건, 배터리 25% 이하 자동복귀, 자동 도킹 성공률 95% 이상, 통신 복구 후 이벤트 누락률 0% |

## 4. 판정 기준 구분

| 항목 | 적용 기준 |
|---|---|
| 차로·주차구획 | 조도 10lx 미만이면 조명 이상 후보 |
| 보행통로 | 조도 50lx 미만이면 조명 이상 후보 |
| 비상구 적치물 | 비상구 전방 1.5m 이내 물체를 긴급 확인 대상으로 분류 |
| 방치물 | 동일 위치에서 2시간 이상 반복 관측된 물체 |
| 바닥·천장·기둥 손상 | 구조안전 확정이 아닌 전문가 현장확인 대상 후보로 분류 |

> 조도 10lx·50lx는 주차장법 시행규칙 관련 기준이다. 비상구 거리, 방치시간 및 탐지 성능 목표는 프로젝트 운영·인수 기준이며 현장 실증 후 확정한다.
