# 시스템 모니터 상세 설계 - 최신 통합본

사용자가 확정한 지하주차장 관제 범위, 화재 이벤트 로그 구성, 예시 UI, 크리티컬 항목 3개를 반영한 draw.io 설계다. `sysmon-detailed-design.drawio`를 draw.io에서 열면 모든 도형·글자·연결선을 편집할 수 있다.

## 페이지 구성

| 탭 | 내용 |
| --- | --- |
| 01 | 전체 플로우차트: 시작·초기 데이터 준비·로그인·독립 수신·대시보드 |
| 02 | 화재 이벤트 수신·사진 파일 저장·DB 저장·로그 반영·예외 |
| 03 | 사건 행 선택·사진 확대·상세 조회·메모 |
| 04 | 신규 → 확인중 → 작업요청 → 조치완료, 권한·버전 확인 |
| 05 | 명령 요청·기록·전달, 미션 모듈 수락·진행·완료·실패 |
| 06 | 순찰·P1~P7 방문·교대 기록, 사건/명령/순찰/교대 검색 |
| 07 | 데이터 계약 합의, 임시 HTTP 검증, 추후 ROS 어댑터 연결 |
| 08 | 지도·좌표 변환, 로봇 상태·영상 갱신, 미수신 처리 |
| 09 | DB 및 데이터 관계: 사용자·로봇·지도·사건·사진·변경·명령·순찰·교대 |
| 10 | 데이터 형식 확정 → 저장·웹 표시 구현 → 실제 통합 검증·촬영 |
| 11 | 메인 대시보드 UI 목업 |
| 12 | 이벤트 상세·증거 이미지 UI 목업 |
| 13 | 로봇 관리·명령 요청 UI 목업 |

01–06은 기능 흐름, 07은 연동 작업 절차, 08은 표시·수신 세부 흐름, 09는 데이터 관계도, 10은 구현·검증 순서, 11–13은 화면 설계다. 모두 같은 종류의 실행 플로우차트는 아니며 설계 설명을 위해 하나의 파일에 묶었다.

## 확정 내용

- 로그: **발생 시각 / 이벤트 종류 / 사건 발생 좌표 / 위험도 상·중·하 / 로봇1 증거 사진 1장**.
- 위험도와 처리 상태는 별개다. 처리 상태·메모·변경 이력은 상세 화면에서 관리한다.
- 사진은 사건 ID와 연결하여 파일로 저장하고 DB에는 대표 이미지 경로를 기록한다. 원본 영상은 DB에 저장하지 않는다.
- 명령 버튼은 요청 생성용이다. 웹이 실제 로봇 실행 완료를 판단하지 않는다.
- 로그인하지 않아도 서버 수신·저장은 계속된다. 로그인은 조회·조작 권한을 제공한다.
- 빈 DB는 사건 0건인 시연 DB를 의미한다. 사용자 계정·지도는 준비하며 서버 재시작 때 이력을 삭제하지 않는다.

## 세부 구현 시 적용할 규칙

- event_id는 사건 연결, message_id는 입력 메시지 중복 확인에 사용한다. 같은 사건의 보완 데이터는 별도 메시지로 기존 사건을 갱신하며 처리 상태를 초기화하지 않는다.
- 좌표·위험도·사진 일부 누락은 사건을 버리지 않고 미수신 상태를 표시하는 예외 처리 제안이다. 값이 임의로 생성되어서는 안 된다.
- 사진 쓰기 실패와 DB 실패는 성공으로 처리하지 않는다. 파일과 DB의 저장 원자성이 다르므로 임시 파일·재처리·잔여 파일 정리 방식을 구현 단계에서 결정한다.
- 이벤트 상태와 변경 이력을 동일 트랜잭션에 저장하고 실패 시 기존 상태를 유지한다. 메모 역시 서버 권한 검사를 적용한다.
- 명령의 응답 지연은 결과 미확인이다. 같은 요청 ID의 결과를 확인하며 새로운 명령을 무조건 재전송하지 않는다.
- 순찰·교대의 시작과 완료는 미션 모듈이 제공하는 기록으로 판단한다. 명령 수락이 순찰 완료를 뜻하지 않는다.
- 지도 표시에는 원점·해상도·축/회전·좌표계를 반영한다. 좌표 불명·지도 버전 불일치는 별도 표시한다.
- 화면 갱신 주기, 상태 기록 주기, 연결 끊김 기준, 명령 재확인 기준은 실제 환경 성능과 미션 계약으로 정한다.

ROS 토픽명·실제 메시지, 화재 판정 및 위험등급 산정, 교대 완료 기준은 아직 팀 협의가 필요하다. 이 설계는 해당 데이터를 Sysmon에서 수신·표시·기록하는 범위이며 화재 인식 알고리즘 구현을 추가하는 문서는 아니다.

10번 탭의 크리티컬 항목은 합의한 관리 항목과 의존 순서를 반영한다. 실제 여유시간이 0인 크리티컬 패스의 계산은 작업별 기간·담당자 일정이 확정된 뒤 수행한다. 샘플 검증과 실제 환경 검증 완료를 구분한다.
