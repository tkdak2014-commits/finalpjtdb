# 각진 형태 정리 기준

- 적용 대상: 원본 `플로우차트.drawio`의 13개 탭.
- 01~10 플로우차트의 시작·종료·대기 도형을 둥근 타원에서 각진 사각형으로 변경.
- 조건 판단은 흐름을 구별할 수 있도록 마름모로 유지.
- 처리·오류·저장·화면 표시 도형은 모서리 반경이 없는 사각형으로 통일.
- 연결선은 곡선을 사용하지 않고 수평·수직으로 꺾이는 직각 연결선으로 통일.
- 선 굵기와 화살표 모양을 통일하고, 분기 라벨의 흰색 배경을 유지해 선과 글자가 겹쳐 보이지 않도록 설정.
- 11~13 UI 목업은 기존 각진 카드·표 형태를 유지하면서 선 두께만 통일.
- 내용·분기·색상·페이지 순서는 변경하지 않음.

수정본은 `플로우차트_각진형태.drawio`이며 원본 다운로드 파일은 변경하지 않았다.
