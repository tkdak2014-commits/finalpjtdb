시작 → 서버·DB → 초기 데이터 → 수신부 → 로그인 → 대시보드 → 상태·지도·영상 → 화재 이벤트 → 사진·DB → 로그 → 상세·메모 → 처리 상태 → 명령 요청 → 이력 → 로그아웃
