# 가로형 상세 설계 사용 안내

`플로우차트_가로형_기능박스.drawio`는 흐름을 왼쪽에서 오른쪽으로 읽도록 다시 배치한 수정본이다.

- 01~10: 가로형 기능·데이터·검증 플로우.
- 11~13: 가로형 UI 목업.
- 처리 도형은 각진 사각형, 조건 판단은 마름모, 연결선은 직각선.
- 01 전체 플로우차트 아래에는 인증·권한, 지도·상태·영상, 이벤트·증거사진, 운영 명령, 순찰·교대·이력의 세부 기능 박스 추가 영역이 있다.

세부 기능을 추가할 때는 아래쪽 점선 박스를 복제하거나, 박스 내부에 작은 사각형을 배치한 뒤 위쪽 관련 단계와 직각 연결선으로 연결한다. 한 박스에는 동사로 시작하는 기능을 하나씩 적는 편이 읽기 쉽다. 예: `로그인 정보 검증`, `화재 이벤트 DB 저장`, `증거 이미지 확대 표시`.

원본 다운로드 파일과 이전 세로형·각진형 수정본은 변경하지 않았다.
